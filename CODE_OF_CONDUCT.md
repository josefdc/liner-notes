# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep criticism about the work.
Harassment and personal attacks are not accepted, in any project space.

To report a problem, use GitHub's
[report feature](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
on the comment or account in question, or contact the maintainer through their
[GitHub profile](https://github.com/josefdc). Reports are handled in confidence.
